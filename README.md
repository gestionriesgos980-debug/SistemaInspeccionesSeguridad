# SistemaInspeccionesSeguridad
Sistema para realizar inspecciones de seguridad, gestionar hallazgos, riesgos y generar informes para clientes.

## CAM-PLANTILLA-01
Primera prueba de integración con la plantilla maestra Word. El sistema puede preparar una copia de la plantilla y alimentar datos básicos de fecha, cliente, puesto, realizado por y revisado por, conservando el documento base. El generador PDF actual se mantiene en paralelo durante la validación.
